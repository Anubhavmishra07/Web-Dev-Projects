CSS : Cascading Style Sheets

CSS describe the visual style and presentation of the content written in html

CSS also has properties just like html attributes to format the content

A CSS rule(Structure) looks like this:
selector {
  property: value;
  property: value;
}
Selector = Which HTML element to style
🔴 Declaration Block { ... }
Everything inside the curly braces is called the declaration block.
{
  property: value;
  property: value;
}
🟠 Declaration / Style
Each line inside the block is a declaration (one styling rule).
 property: value;
🟡 Property
Property = What aspect you want to change 
🟡 Value
Value = How you want it to look
example-
h1 {
  color: blue;
  text-align: center;
  font-size: 20px;c
  }

There are 3 main ways to write CSS in HTML:
✅ 1) Inline CSS
CSS is written directly inside an HTML tag using the style attribute.
example- <h1 style="color: blue; font-size: 20px;">Hello World</h1>
🔹 Applies style to only that one element
🔹 Quick but NOT recommended for large projects
Use when: Small changes or testing

✅ 2) Internal CSS (Embedded CSS)
CSS is written inside the <style> tag in the <head> section of the HTML file.
example - <!DOCTYPE html>
<html>
<head>
  <style>
    h1 {
      color: blue;
      text-align: center;
    }
  </style>
</head>
<body>
<h1>Hello World</h1>
</body>
</html>
🔹 Applies to the whole page
🔹 Good for single-page websites

✅ 3) External CSS (Best Method ⭐)
CSS is written in a separate .css file and linked to the HTML.
🔹 Can style multiple pages
🔹 Keeps code clean
🔹 Most professional and widely used
Step 1 — Create CSS file (style.css)
Step 2 — Link it in HTML
<head>
  <link rel="stylesheet" href="style.css">
</head>

The external css file can be named anything and there is no hardcore convention like index.html

In css we use /* comment */ for commenting single as well as multilines.

The semicolon (;) is compulsory in CSS to end every declaration within a declaration block.

In order to keep html enities or encoding away from css file so that changing html coding doesn't bring changes in css file we use id and classes . This helps us in maintaining the code easily and change in html code won't bring any change to the css file .The difference btwn id and classes is that we are not allowed to repeat id names and thus each id name or value can be used only once but using classes allows us to assign same names to multiple elements .

Using class or id simply eliminates code repeatabilty and allows easy modifications.

A class or property with more than one word is generally separated by a - instead of space in css/html as a convention. 

In real world we always use classes instead of id for versatility or maintainability .

Colors in css can be applied by using rgb(r,g,b) or rgba(r,g,b,transparency value or alpha value) where r,g,b lies from 0 to 250 and aplha value lies from 0 to 1 or hexadecimal notation like #00ffff (which is same as #0ff when color codes are identical pairs)or hsl (hue value,saturation value in %,lightness value in %) ex - (40,100%,50%) .

Hyperlinks are generally styled in LVHA (link,visited,hover,active) order only for proper working of all css.

To resolve conflicting declarations (same property being implemented via different declaration blocks) the following rules (aka Specificity)are used:

i)'!important' is used to force a CSS rule to override all other rules, even if they normally have higher priority.
ex - selector {
  property: value !important;
} hence !important has the highest property but it should not be used bcoz !important overrides everything leading to messy, unstructured CSS and thus harder to modify or extend styles later
ii) inline style are 2nd highest 
iii) id(#) selector
iv) class(.) or pseudo-class(:) selector
v) element selector (p,div,li,etc.)
vi) universal selector(*) has the least priority
if conflict is btwn same selectors than last selector is applied to the element.

Use space-separated class names inside the class attribute to assign multiple classes to one element.
<p class="class1 class2 class3">Hello World</p> here class1,class2,class3 now act as three separate classes for the same element p 
<p class="text red bold">This is a paragraph</p>
.text {
  font-size: 18px;
}
.red {
  color: red;
}
.bold {
  font-weight: bold;
}
<p class="red" class="bold">Hello</p>
This is invalid HTML and the browser will usually ignore the first one and only apply the last class ("bold") .

🌿 Inheritance in CSS
Inheritance means that some CSS properties applied to a parent element are automatically passed down to its child elements. ex- HTML
<div>
  <p>Hello World</p>
</div>
CSS
div {
  color: blue;
}
Here the <p> text will become blue, even though we didn’t style <p> directly.
✅ Properties That Inherit
Common properties that do inherit are generally text related:
color
font-weight
font-style
line-height
letter-spacing
text-transform
text-shadow
list-style
font-size
font-family
text-align
visibility

⚡Override Inheritance
Child can override parent style:
div {
  color: blue;
}
p {
  color: red;
}
<p> will be red, not blue . Note that this is not because of specificity it’s because of direct styling which always overrides inherited values. Inheritance has lower priority than direct declarations.Specificity matters when multiple rules target the SAME element DIRECTLY 
ex - <p class="text">Hello</p>
p {
  color: blue;
}
.text {
  color: red;
}

Universal selector simply applies to all elements of the webpage and there is no inheritance involved . They can easily be overridden by selectors having higher priority than it .It is a good practice to use universal selector as a global reset to the page before starting any styling-
* {  
  margin: 0; 
  padding: 0;  
}

Background is the content area + padding area of the element.

Either use margin-bottom or use margin-top to create vertical space btwn elements , do not mix of them to avoid any misalignments.

<ul>/<ol> usually have some defualt paddings in order to display the bullet points and numbers .<ul>/<ol> defines list style (bullets or numbers),that is,the bullets and numbers are controlled by the parent list and not by <li>.
<li> → just represents each list item (content) .

If two margins occupy the same then they aren't added up rather they collapse into each other and the final margin is the larger btwn the two.

'height' and 'width' properties represent the height and width of the element inside the border except the padding . In simple words it is basically the height and widht of the content of the element.We specify these properties of the element in the CSS only instead of the html and in CSS writing unit is mandatory .

The child elements can't be larger or wider than the parent elements .

Normal flow vs Absolute Positioning -

Normal flow:
>defualt Positioning
>elements are said to be "in flow"
>elements are simply laid out according to their order in the HTML code
In order to set any element to normal flow we use CSS:
position:relative

Absolute Positioning:
>element is removed from normal flow and said to be "out of flow"
>no impact on surrounding elements,might overlap them
>we use top,bottom,left or right to offset the element from its relatively positioned container
In order to set any element to normal flow we use CSS:
position:absolute
>By default the absolute positioning is done wrt to the view port or simply from the first view of the webpage .
>In order to change the absolute position wrt to something else then the element's parent element must be given the property- position:relative; so that the absolute position is decided wrt to that parent element and not the view port.Also,if multiple parents are given the property -position:relative; then the immediate or the closest parent is the deciding factor and others are ignored.

Pseudo Elements -
These are elements which do not exist in HTMl but we can still select and style them in CSS.A pseudo-element is used to style a specific part of an element or to create virtual elements inside it.Ex-first line or first letter of the paragraph ,etc.
Pseudo elements are written or selected using two colons (::)in CSS .They are by defualt inline elements.

Adjacent element selector/Adjacent Sibling selector:
A Sibling element is basically part of the same parent.
ex - <body>
<p></p>
<strong></strong>
<button></button>
</body>
then button,p,strong are all siblings but p and strong are Adjacent siblings and strong and button are also Adjacent siblings. + is used to select adjacent sibling
ex-p+strong will select all the adjacent strong sibling elements of p element.
